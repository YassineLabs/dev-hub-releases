# Security

Please report security issues privately — do not open a public issue.

- Use **Security → Report a vulnerability** on this repository, or
- email **yassineoujaa42@gmail.com** with "Dev Hub security" in the subject.

Include the Dev Hub and macOS versions, steps to reproduce, and the impact you observed. Reports are acknowledged within 5 working days, and a disclosure date is agreed with you once a fix is available. Only the latest release receives security fixes.

Release builds are signed with an Apple Developer ID, notarized by Apple, and published with SHA-256 checksums. Dev Hub has no auto-update mechanism and makes no network requests of its own.
